# 📝 To-Do List Kelompok 5

## 📌 Deskripsi Proyek

To-Do List Kelompok 5 merupakan aplikasi web sederhana yang digunakan untuk mencatat, mengelola, dan memantau daftar tugas atau pekerjaan sehari-hari.

Aplikasi ini dikembangkan sebagai bagian dari Praktikum Rekayasa Perangkat Lunak (RPL) dengan menerapkan metode pengembangan Agile/Scrum serta penggunaan Git dan GitHub sebagai sarana kolaborasi antaranggota tim.

Pengguna dapat menambahkan tugas baru, menandai tugas yang telah selesai, menghapus tugas, serta melihat jumlah tugas yang tersedia dalam daftar.

## ✨ Fitur Aplikasi

Aplikasi To-Do List ini memiliki beberapa fitur utama, yaitu:

1. **Menambahkan Tugas**  
   Pengguna dapat menuliskan tugas pada kotak input dan menambahkannya ke dalam daftar melalui tombol Tambah.

2. **Menandai Tugas Selesai**  
   Pengguna dapat mengklik tugas untuk menandainya sebagai tugas yang telah selesai. Tugas yang selesai akan ditampilkan dengan efek coretan.

3. **Menghapus Tugas**  
   Pengguna dapat menghapus tugas dari daftar dengan melakukan klik dua kali pada tugas yang ingin dihapus.

4. **Menghitung Jumlah Tugas**  
   Aplikasi menampilkan jumlah tugas yang terdapat dalam daftar secara otomatis, termasuk ketika tugas ditambahkan atau dihapus.

5. **Tampilan Sederhana dan Responsif**  
   Aplikasi memiliki tampilan yang sederhana, rapi, dan mudah digunakan.

## 🛠️ Teknologi yang Digunakan

Pengembangan aplikasi ini menggunakan:

- **HTML5** – Membuat struktur halaman web.
- **CSS3** – Mengatur tampilan dan desain aplikasi.
- **JavaScript** – Mengimplementasikan fungsi dan interaksi aplikasi.
- **Git** – Mengelola versi kode selama proses pengembangan.
- **GitHub** – Menyimpan repository dan mendukung kolaborasi antaranggota kelompok.

## 🚀 Cara Menjalankan Aplikasi

Untuk menjalankan aplikasi To-Do List, ikuti langkah-langkah berikut:

1. Clone repository dari GitHub menggunakan perintah:

   ```bash
   git clone https://github.com/Syithah15/todo-kelompok-5.git
   ```

2. Masuk ke folder proyek:

   ```bash
   cd todo-kelompok-5
   ```

3. Buka folder proyek menggunakan File Explorer atau Visual Studio Code.

4. Jalankan aplikasi dengan membuka file `index.html` menggunakan browser (Google Chrome, Microsoft Edge, atau browser lainnya).

5. Aplikasi siap digunakan.

## 📂 Struktur Folder

```text
todo-kelompok-5/
```

- `hitung.js`: Mengatur perhitungan jumlah tugas secara otomatis.

## 🔄 Metode Pengembangan

Proyek ini dikembangkan menggunakan metode Agile dengan kerangka kerja Scrum melalui tahapan:

1. **Sprint Planning** – Menentukan kebutuhan aplikasi, menyusun product backlog, dan membagi tugas setiap anggota.
2. **Sprint Execution** – Melaksanakan pengembangan aplikasi sesuai pembagian user story.
3. **Daily Scrum** – Melakukan koordinasi singkat untuk mengetahui perkembangan pekerjaan dan kendala setiap anggota.
4. **Integration** – Menggabungkan kode dari setiap anggota melalui Pull Request, Code Review, dan Merge.
5. **Sprint Review** – Melakukan demonstrasi dan pemeriksaan hasil aplikasi.
6. **Sprint Retrospective** – Mengevaluasi proses kerja kelompok untuk mengetahui hal yang sudah berjalan baik dan hal yang perlu diperbaiki.

Proyek ini bertujuan untuk menerapkan konsep Rekayasa Perangkat Lunak dalam pengembangan aplikasi sederhana, memahami proses kerja menggunakan metode Scrum, serta meningkatkan kemampuan kolaborasi tim melalui penggunaan Git dan GitHub.
